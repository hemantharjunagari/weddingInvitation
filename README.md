## 🚀 How to Push to GitHub & Host on Vercel / GitHub Pages

### Step 1: Initialize Git and Commit
In your terminal, inside `/Users/hemantharjunagari/work/weddingInvitation`, run:

```bash
git init
git add .
git commit -m "Initial commit: Arjunagari Family Wedding Invitation Website"
```

### Step 2: Push to Your New GitHub Repository
1. Go to [GitHub.com/new](https://github.com/new) and create a repository (e.g., `wedding-invitation` or `weddingInvitation`).
2. Run:
```bash
git branch -M main
git remote add origin https://github.com/<YOUR_GITHUB_USERNAME>/<YOUR_REPO_NAME>.git
git push -u origin main
```

---

### 🌐 Option A: Host on Vercel (Recommended)
1. Go to [Vercel.com](https://vercel.com) and log in with your GitHub account.
2. Click **"Add New Project"** -> **"Import Git Repository"**.
3. Select your repository.
4. Framework Preset: Leave as **Other** (it's a clean static HTML/CSS/JS site).
5. Click **Deploy**.
6. In ~15 seconds, your wedding invitation will be live at `https://your-project-name.vercel.app` with free SSL and instant global CDN!

*(You can also use a custom domain on Vercel like `lakshmipraveenwedding.com` at any time!)*

---

### 🌐 Option B: Host on GitHub Pages (Free)
1. In your GitHub repository, go to **Settings** -> **Pages**.
2. Under **Build and deployment > Source**, select **Deploy from a branch**.
3. Branch: choose `main` and folder `/ (root)`.
4. Click **Save**.
5. Your website will be live in 1-2 minutes at `https://<YOUR_GITHUB_USERNAME>.github.io/<YOUR_REPO_NAME>/`.
